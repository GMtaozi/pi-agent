## 修复 workspace 包缺失依赖声明

CI/CD 构建报错 `@workforge/logging` 模块找不到。

**根因**：多个子包的 `package.json` 缺少对 `@workforge/logging` 的 workspace 依赖声明。源码中通过 `import { Logger } from '@workforge/logging'` 引用，但 package.json 的 dependencies 里没有写。本地之所以"看起来能跑"是因为 node_modules 可能有 hoisting，但 CI 环境下 pnpm 严格按声明安装，未声明的依赖不会被链接。

**修复清单**（4 个包）：
1. `packages/schedule/package.json` — 新增 `"@workforge/logging": "workspace:*"`
2. `packages/workspace/package.json` — 新增 `"@workforge/logging": "workspace:*"`
3. `packages/tools/package.json` — 新增 `"@workforge/logging": "workspace:*"`
4. `packages/governance/package.json` — 新增 `dependencies` 块并声明 `"@workforge/logging": "workspace:*"`

**验证**：四个包 `pnpm --filter @workforge/X run build` 全部通过（exit 0）。

**教训**：pnpm workspace 中，所有跨包引用（即使是 workspace 内的包）都必须在消费方的 `package.json` 中显式声明。不能依赖 hoisting。CI 是照妖镜。
