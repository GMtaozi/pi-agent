## 0. 现状勘察结论（本 PRD 的立论基础）

M6 不是功能补齐，而是**从"企业协作工具"向"企业级 AI Agent 平台 + 托管服务"的战略跃迁**。经过 M1-M5 六轮迭代，pi-agent 已具备：多租户底座、RBAC 权限、审批流、审计合规、计费订阅、插件生态、模板市场。M6 要做的是**把这些能力产品化、行业化、规模化**。

| 维度 | M5 成果（可复用资产） | M6 差距 |
|------|----------------------|---------|
| **行业方案** | 模板市场有通用模板 | 无行业专用方案包（金融/医疗/教育），无预置知识库+工作流 |
| **云端托管** | 私有化 License + 订阅计费 | 无 SaaS 托管、无免费额度、无按 Token/Agent 计费 |
| **企业版能力** | RBAC + 审计 + SSO 雏形 | 无 SAML、无 SLA 保障、无混合部署 |
| **市场化** | 产品可用 | 无官网、无案例、无品牌认知 |

**可复用资产**：
- M4 的 `subscriptions` / `quota_policies` / `invoices` → 订阅计费直接复用
- M4 的 RBAC + 审计 → 企业合规基础
- M3 的模板市场 → 行业模板载体
- M2 的知识库 / 工作流引擎 → 行业方案核心组件

## 1. 行业解决方案包

### 1.1 方案包结构

每个行业方案包是一个**一体化交付单元**，包含四层：

```
行业方案包
├── 行业模板（Agent 人设 + 提示词 + 工具链）
├── 预置知识库（行业语料 / 法规 / 术语表）
├── 预置工作流（典型业务场景的自动化流程）
└── 行业配置（合规模板、SLA 策略、数据保留策略）
```

### 1.2 三大行业方案

| 行业 | 核心场景 | 关键能力 | 合规要求 |
|------|---------|---------|---------|
| **金融** | 合规审查、投研助手、风险预警 | 研报解析、舆情监控、反洗钱检查 | 等保 2.0 三级、数据本地化、留痕 7 年 |
| **医疗** | 文献检索、辅助问诊、病历结构化 | 医学 NLP、ICD 编码映射、循证检索 | HIPAA 等效、患者数据脱敏、伦理审查 |
| **教育** | 个性教学、智能答疑、作业批改 | 学情分析、知识点图谱、自适应推荐 | 未成年人保护、内容安全、教育数据规范 |

### 1.3 方案包交付标准

| 组件 | 最低交付标准 |
|------|------------|
| 行业模板 | ≥ 5 个 Agent 模板（含系统提示词、工具链、示例对话） |
| 预置知识库 | ≥ 1000 篇行业文档 / 法规 / 术语表（向量化入库） |
| 预置工作流 | ≥ 3 个端到端工作流（含触发条件、审批节点、输出格式） |
| 行业配置 | 合规策略模板（审计留存、数据脱敏、审批触发条件） |

### 1.4 用户故事

**US-F1：金融合规经理**
> 作为银行合规经理，我希望一键部署"反洗钱审查 Agent"，让它自动分析大额交易报告并标记可疑案例，以便将人工审查效率提升 5 倍。

**US-M1：医学研究员**
> 作为医学研究员，我希望部署"文献检索助手"，让它每周自动检索 PubMed 新文献并生成结构化摘要，以便紧跟前沿进展。

**US-E1：教育机构讲师**
> 作为教育机构讲师，我希望使用"智能答疑 Agent"，让它根据学生答题数据生成个性化练习推荐，以便实现因材施教。

## 2. 云端托管服务

### 2.1 服务模式

| 模式 | 部署 | 计费 | 目标客户 |
|------|------|------|---------|
| **SaaS 公有云** | pi-agent 托管 | 免费额度 + 订阅 + 按量 | 中小团队、开发者 |
| **专属云** | 独立资源池 | 订阅 + 用量 | 中大企业 |
| **私有化** | 客户环境 | License 年费 | 金融/政府/医疗 |

### 2.2 计费模型（参考 Dify Cloud）

| 维度 | 免费层 | 专业版 | 企业版 |
|------|--------|--------|--------|
| **月费** | ¥0 | ¥299/月 | 定制 |
| **Token / 月** | 50 万 | 500 万 | 不限（按量） |
| **Agent 数** | 3 | 20 | 不限 |
| **成员数** | 2 | 10 | 不限 |
| **存储** | 500 MB | 10 GB | 定制 |
| **LLM 调用** | 限定模型 | 全模型 | 全模型 + 私有模型 |
| **知识库文档** | 100 篇 | 5000 篇 | 不限 |
| **工作流执行** | 1000 次/月 | 5 万次/月 | 不限 |
| **支持** | 社区 | 工单 24h | 专属 + SLA |

### 2.3 免费额度策略

| 维度 | 策略 | 目的 |
|------|------|------|
| **注册赠额** | 注册即送 50 万 Token（一次性） | 降低体验门槛 |
| **月度免费** | 每月 1 万 Token（保底） | 防止"零用"流失 |
| **试用升级** | 企业版 14 天试用（需绑定支付方式） | 驱动付费转化 |
| **推荐奖励** | 邀请注册各得 10 万 Token | 病毒传播 |

### 2.4 配额与限流

| 套餐 | API 速率 | LLM 速率 | 并发 Agent |
|------|---------|---------|-----------|
| 免费 | 10/min | 5/min | 1 |
| 专业 | 100/min | 50/min | 5 |
| 企业 | 定制 | 定制 | 定制 |

### 2.5 用户故事

**US-C1：开发者**
> 作为独立开发者，我希望免费注册即可体验完整 Agent 能力，以便评估是否值得付费。

**US-C2：创业团队**
> 作为 10 人创业团队，我希望按 ¥299/月订阅专业版，获得足够 Token 和 Agent 数支撑日常使用。

**US-C3：企业采购**

## 3. 企业版能力

### 3.1 身份与访问

| 能力 | 规格 | 优先级 |
|------|------|--------|
| **SSO (OIDC/SAML 2.0)** | 标准协议对接，支持 Azure AD / Okta / 企业微信 | P0 |
| **LDAP / AD 同步** | 部门与用户自动同步 | P1 |
| **MFA** | TOTP / WebAuthn（FIDO2） | P0 |
| **会话管理** | 强制登出、并发会话限制、IP 白名单 | P1 |

### 3.2 SLA 保障

| 级别 | 可用性 | 支持响应 | 赔偿 |
|------|--------|---------|------|
| **标准** | 99.5% | 工单 24h | 无 |
| **高级** | 99.9% | 4h 响应 + 专属群 | 月费 10%/小时 |
| **旗舰** | 99.95% | 1h 响应 + 专属 CSM | 月费 20%/小时 |

### 3.3 混合部署（云 + 私有化）

```
┌─────────────────────────────────────────────┐
│            统一控制平面（Cloud）               │
│  计费 · 监控 · 审计 · 模板市场 · 知识库同步     │
└──────────────────┬──────────────────────────┘
                   │ 加密通道（WireGuard/TLS）
       ┌───────────┴───────────┐
       ▼                       ▼
┌─────────────┐         ┌─────────────┐
│  公有云租户  │         │ 私有化节点   │
│  SaaS 实例  │         │ 客户环境     │
└─────────────┘         └─────────────┘
```

- **控制平面在云**：计费、监控、模板市场、知识库同步由云端统一管理
- **数据平面可选**：敏感数据可驻留私有化节点，非敏感计算可弹性上云
- **单向同步**：私有化 → 云端仅同步元数据（用量、监控），不同步业务数据

### 3.4 用户故事

**US-E1：企业 IT 管理员**

**US-E2：合规官**

## 7. 风险与应对

| 风险 | 等级 | 应对 |
|------|------|------|
| **行业方案"通用化"**（客户觉得不够深） | 高 | 每行业至少 1 家共创客户深度打磨；方案包可定制扩展 |
| **云端获客成本过高** | 高 | 免费额度 + 推荐奖励 + 内容营销；控制 CAC < LTV/3 |
| **SAML 集成复杂度超预期** | 中 | 优先 OIDC（更现代），SAML 作为 P1；提供 IdP 配置向导 |
| **混合部署网络连通性问题** | 中 | 提供部署探针工具；支持离线模式（降级为纯私有化） |
| **SLA 赔偿风险** | 中 | 多层级 SLA（非旗舰不赔）；可用性监控 + 自动故障转移 |
| **竞品价格战** | 中 | 差异化在"行业深度"而非价格；企业版绑定服务价值 |
