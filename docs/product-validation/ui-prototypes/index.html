使用方式
每个页面为独立 HTML，使用 Tailwind CDN + 共享 design-system.css / design-system.js。
主题：<html data-theme="dark|light"> ，右上角按钮或 design-system.js 自动持久化。
响应式断点：1024px（侧栏转抽屉）/ 640px（移动端）。交互状态（hover / active / disabled / selected）均已覆盖。
pi-agent UI 原型 · 由 ui-designer 输出 · 与 apps/web 现有设计语言（index.css）保持一致
