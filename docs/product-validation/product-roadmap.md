## 一、执行摘要

### 1.1 战略定位

pi-agent 当前在**技术架构（4.8）**、**安全设计**、**调试能力（自研 Debug Panel）**、**部署方案（Docker/PM2/Nginx/SSL）**上具备明显差异化优势，但在**生态规模**、**模型接入广度**、**协作功能**、**商业化工具**上与 Dify / Coze / FastGPT 存在差距。

未来 6 个月的核心战略：**以"私有化企业部署 + AI Agent 可观测性"为护城河，用插件市场与模板生态补齐平台型短板，用商业化工具完成从工具到平台的闭环。**

### 1.2 三大战略支柱

| 支柱 | 含义 | 对标差距 | 落地阶段 |
|------|------|----------|----------|
| **护城河** | 私有化部署 + 可观测性 + 安全合规 | 差异化领先 | M1、M5 |
| **平台化** | 插件市场 + 模板市场 + MCP 生态 | 追平 Dify 生态 | M2、M3 |
| **商业化** | 用量计费 + 行业方案 + 云端托管 | 补齐变现能力 | M4、M6 |

## 三、月度阶段详解

### M1 — 企业刚需补完（2026.09 – 2026.10）

**核心目标**：补齐生产环境与企业管理的刚需能力，让平台具备"规模化运营"基础，结束"个人玩具"印象。

**关键功能**
1. **批量操作**（TC-017，原缺失）：Agent / 知识库 / 工作流的批量选择、删除、导出、权限变更，带二次确认与操作进度。
2. **Prompt 优化工具**：Prompt 版本对比、A/B 测试（同一任务双 Prompt 并行评估）、效果评分（相关性/完整性/合规性），沉淀为 Prompt 模板库。
3. **成本分摊增强**：在现有监控面板 Token/成本基础上，新增"按团队/项目/成员"的成本分摊与预算阈值。
4. **通知告警深化**（基于已完成的 NotificationService）：补充告警历史、静默窗口、飞书/钉钉国内渠道，对接成本超阈值/失败率/耗时。
5. **模型接入广度收尾**：验证通义/智谱/文心/Ollama 全量接入稳定性与故障转移（任务基线已扩展，本月回归测试）。

**成功指标**
- 批量操作功能覆盖率 100%，P2 用例 TC-017 通过率 ≥ 95%
- Prompt 优化工具周活跃使用率 ≥ 30%（数据分析师追踪）
- 成本分摊覆盖 100% 活跃租户
- 模型接入数 ≥ 6，单模型故障不影响总体（降级验证通过）

---

### M2 — 模板市场 & RAG 深度（2026.10 – 2026.11）

**核心目标**：降低非技术用户与 PM/BA 的上手门槛，缩小与 FastGPT 在 RAG 深度上的差距。

**关键功能**
1. **模板市场**：官方模板 + 用户共建模板（发布/收藏/评分/一键克隆），打通"从描述创建"与模板。
2. **行业模板包**：法律、医疗、金融、客服、教育 5 类行业专属模板（用户研究员主导场景调研）。
3. **知识库深度对标 FastGPT**：可调切片策略（按段落/固定长度/语义）、嵌入模型可选、检索精度调优（rerank、混合权重）。
4. **模板/知识库一键分享**：团队内共享 + 导出导入（为 M3 插件生态铺垫）。

**成功指标**
- 模板市场模板数 ≥ 20，用户共建占比 ≥ 30%
- 内容创作者契合度 68% → 80%，PM/BA 契合度 72% → 82%
- 知识库检索准确率（人工评测集）提升 ≥ 15%
- 模板带来的 Agent 创建占比 ≥ 40%

---

### M3 — 插件市场 & MCP 生态（2026.11 – 2026.12）

**核心目标**：建立平台型生态，追平 Dify 的 Marketplace 规模，接入 AI 工具开放协议。

**关键功能**
1. **插件市场（Marketplace）**：Provider 插件（模型）、工具插件（搜索/图像/数据库/HTTP）、知识源插件（Notion/Confluence/Google Drive），支持一键安装与版本管理。
2. **MCP 支持**：MCP Server 接入 + MCP Client 能力，使 pi-agent 可调用外部 MCP 工具生态。
3. **开发者接入规范**：插件 SDK、提交审核流程、沙箱执行（复用现有 skills/sandbox 体系）。
4. **生态激励计划**：贡献榜单、官方认证插件标识。

**成功指标**
- 上架插件 ≥ 30（含官方 ≥ 12）
- MCP Server/Client 接入 ≥ 10 个主流工具
- 插件安装渗透率（安装插件的租户占比）≥ 50%
- 开发者贡献 PR ≥ 20（社区/内部）

---

### M4 — 协作增强 & 商业化（2026.12 – 2027.01）

**核心目标**：补齐企业级协作底座，建立用量计费与套餐体系，启动变现闭环。

**关键功能**
1. **RBAC 细粒度权限**：角色/资源/操作三维权限，部门级数据隔离。
2. **审批工作流**：Agent 发布、高危工具调用、成本超阈值的人工审批。
3. **操作审计日志**（治理包增强）：全量操作留痕、可检索、可导出合规报告。
4. **用量与计费系统**：Token/成本计量、团队配额、API 速率限制策略、套餐（免费/团队/企业）。
5. **商业化后台**：License / 订阅管理、用量账单。

**成功指标**
- 企业客户（付费或 POC）≥ 5 家
- 内测付费转化率 ≥ 5%，ARR 启动计量
- RBAC 权限测试覆盖 100% 资源类型
- 审计日志覆盖率 100%，合规自评通过

---

### M5 — 可观测性 & AI 网关（2027.01 – 2027.02）

**核心目标**：在已验证的调试面板优势上，建立全行业差异化壁垒（对标 Langfuse / Arize）。

**关键功能**
1. **AI Agent 可观测性平台**：基于 Debug Panel 扩展——Agent 行为追踪、调用链拓扑、异常检测与根因分析、质量评估（幻觉/偏离）。
2. **企业级 AI 网关**：多模型智能路由与负载均衡、成本优化（按任务自动选性价比模型）、合规审查（敏感词/输出审核）、统一限流。
3. **评测与基准（LLMOps）**：数据集管理、模型/Agent 评估、回归测试。

**成功指标**
- 可观测性平台 DAU（DevOps+开发者）≥ 40%
- 网关路由占比 ≥ 50%，平均成本下降 ≥ 15%
- 异常自动检测准确率 ≥ 85%，告警误报率 < 10%
- 评测数据集覆盖核心场景 ≥ 20 个

---

### M6 — 行业方案 & 云端托管（2027.02 – 2027.03 收尾）

**核心目标**：完成"企业级 AI Agent 平台"转型，对外提供托管服务，规模化变现。

**关键功能**
1. **行业解决方案包**：金融（合规审查/投研助手）、医疗（文献检索/辅助问答）、教育（个性教学/智能答疑），含模板+知识库+工作流一体化。
2. **云端托管服务**：免费额度 + 订阅计费，按 Token / Agent 数计费（参考 Dify Cloud）。
3. **企业版能力**：SSO / SAML、SLA 保障、专属支持、私有化+云混合部署。
4. **市场化动作**：官网改版、案例发布、开发者大会/黑客松。

**成功指标**
- 行业方案 ≥ 3 套，含落地客户案例 ≥ 1 家/行业
- 云端注册数 ≥ 200，付费订阅 ≥ 12%
- 企业版合同 ≥ 3 家，营收形成正向现金流预期
- 市场竞争力评分 3.8 → 4.6

## 四、用户研究洞察（用户研究员）

支撑路线图优先级排序的用户证据（来自 `user-personas-and-test-cases.md` 与验证报告）：

- **企业开发者（契合度 92%）**：API 完整、部署好，但"模型接入偏少"是首要痛点 → M1 模型广度收尾、M3 插件市场直接受益。
- **DevOps（90%）**：告警通知已补齐基础，本月深化；关注可观测性 → M5 重点。
- **PM/BA（72%）、内容创作者（68%）**：技术门槛偏高、缺发布能力 → M2 模板市场 + M6 一键发布/云端托管。
- **独立开发者（85%）**：缺云端托管与成本控制 → M4 计费、M6 云端。

**结论**：M1–M2 优先解决"企业刚需 + 非技术门槛"，M3–M4 建立生态与变现，M5–M6 用差异化与行业方案拉开身位，顺序与用户痛点强度一致。

## 八、成功指标追踪体系（数据分析师）

| 多模型适配复杂度膨胀 | 技术 | 中 | 中 | 标准化 Provider 接口（已奠基），M3 插件化隔离 |
| 商业化节奏过快导致体验受损 | 执行 | 中 | 中 | M4 计费以内测灰度，避免影响核心免费功能 |
| 前端性能（大型工作流/看板） | 技术 | 低 | 中 | M2/M5 虚拟化渲染 + 代码分割（Phase-6 已有基础） |

**总体风险评级**：中。最大不确定性在 M3 生态冷启动与 M6 云端托管的运维成本，建议以 M1–M2 的刚需功能先固化存量企业客户，再用存量需求反哺生态与商业化。
