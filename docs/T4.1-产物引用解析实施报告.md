## 一、实现内容

### 1. 文件引用解析器（packages/workspace/src/file-ref-parser.ts）

**功能**：
- 解析用户消息中的文件引用
- 支持多种引用格式：
  - `@filepath` 或 `filepath`
  - `"filepath"`（带引号）
  - `文件 filepath`（中文前缀）
- 支持的扩展名：html, css, js, ts, jsx, tsx, json, md, txt, py, java, cpp, c, h, go, rs, yaml, yml, toml

**输出**：
- `ParsedMessage`：包含清理后的文本和文件引用列表
- `FileReference`：包含原始引用、路径、类型

### 2. 上下文构建器（packages/workspace/src/context-builder.ts）

**核心方法**：

#### `buildWorkspaceContext(workspaceId, userMessage)`
1. 获取工作台文件列表（最多 20 个）
2. 解析用户消息中的文件引用
3. 读取引用文件的内容（每个文件最多 50KB）
4. 返回 `WorkspaceContext` 包含：
   - `files`：工作台文件列表
   - `referencedFiles`：引用文件的内容

#### `buildSystemPrompt(workspaceContext)`
- 构建系统提示词，包含：
  - 工作台文件列表
  - 引用文件内容（代码块格式）
  - 工具使用说明

#### `buildUserMessageWithContext(userMessage, workspaceContext)`
- 在用户消息末尾追加系统提示
- 格式：`[System: Referenced files loaded: path1, path2]`

### 3. 服务端集成（apps/server/src/index.ts）

**会话-工作台映射**：
- 新增 `sessionWorkspaces` Map 存储 sessionId -> workspaceId 映射
- 创建会话时记录 workspaceId
- 发送消息时查找对应工作台

**Prompt 端点增强**：
```typescript
// Build workspace context for file references
const workspaceId = sessionWorkspaces.get(id) || 'default';
const workspaceContext = await contextBuilder.buildWorkspaceContext(workspaceId, text);

const response = await agentEngine.prompt(id, text, workspaceContext);
```

### 4. Agent 引擎集成（packages/agent-engine/src/engine.ts）

**prompt 方法增强**：
- 新增可选参数 `workspaceContext?: WorkspaceContext`
- 使用 `contextBuilder.buildUserMessageWithContext` 构建用户消息
- 将引用文件内容注入到 Agent 上下文中

## 三、使用示例

### 用户输入
```
把 @5.html 的标题改大，并给 index.css 添加深色背景
```

### 系统处理
1. 解析出文件引用：`['5.html', 'index.css']`
2. 读取这两个文件的内容
3. 构建用户消息：
   ```
   把 @5.html 的标题改大，并给 index.css 添加深色背景
   
   [System: Referenced files loaded: 5.html, index.css]
   ```
4. Agent 收到消息后可以看到文件内容，进行修改

### Agent 输出
Agent 可以：
- 读取文件内容
- 调用 edit 工具修改文件
- 返回修改摘要
