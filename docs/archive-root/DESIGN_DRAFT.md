# WorkForge 监控页面设计稿

## 当前问题分析

### 1. 信息层级不清晰
- 所有数据平铺展示，没有主次之分
- 关键指标（错误率、响应时间）不够突出
- 缺乏视觉引导，用户难以快速定位问题

### 2. 数据可视化不足
- 只有表格和数字，缺少趋势图表
- 无法直观看到请求量、响应时间的变化趋势
- 系统资源（CPU/内存）没有可视化

### 3. 交互体验待优化
- 没有 Tab 切换，页面过长
- 告警和日志混在一起，查找困难
- 缺少时间范围选择（1小时/24小时/7天）

### 4. 视觉设计
- 卡片样式单一，缺少层次感
- 颜色使用不统一
- 字体大小和间距需要调整

---

## 设计方案

### 设计风格
- **风格**: 现代简约 + 数据可视化优先
- **配色**: 深色模式为主，蓝色为主色调，红/黄/绿作为状态色
- **字体**: 系统字体栈，数字使用等宽字体

### 布局结构

```
┌─────────────────────────────────────────┐
│ 监控中心                    健康 ● 运行时间 │
├─────────────────────────────────────────┤
│ [总览] [工具] [告警] [日志] [性能]         │
├─────────────────────────────────────────┤
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐   │
│ │总请求│ │成功率│ │平均响应│ │活跃连接│   │
│ │ 1,234│ │ 99.5%│ │ 245ms │ │   42  │   │
│ └──────┘ └──────┘ └──────┘ └──────┘   │
├─────────────────────────────────────────┤
│ 请求量趋势图              │ 响应时间趋势图 │
│ [Area Chart]              │ [Line Chart]  │
├─────────────────────────────────────────┤
│ 系统资源监控              │ 错误统计      │
│ [Memory/CPU Chart]        │ [Bar Chart]   │
└─────────────────────────────────────────┘
```

### 核心改进点

1. **顶部状态栏**
   - 左侧：页面标题"监控中心"
   - 右侧：健康状态徽章 + 运行时间

2. **Tab 导航**
   - 总览 / 工具统计 / 告警 / 日志 / 性能
   - 底部边框高亮当前选中

3. **关键指标卡片（KPI Cards）**
   - 6 张卡片：总请求、成功率、平均响应、活跃连接、内存、错误数
   - 卡片包含：标题、大号数字、辅助信息（成功/失败、P95/P99）
   - 悬停效果：轻微上浮 + 阴影加深

4. **图表区域**
   - 2x2 网格布局
   - 请求量趋势：面积图（Area Chart）
   - 响应时间：折线图（Line Chart）
   - 系统资源：双轴面积图（内存 + CPU）
   - 错误统计：柱状图（Bar Chart）

5. **工具统计 Tab**
   - 表格展示：工具名、调用次数、平均耗时、成功率、慢调用
   - 成功率颜色编码：绿色(≥99%) / 黄色(≥90%) / 红色(<90%)

6. **告警 Tab**
   - 错误列表表格
   - 时间、服务、消息、堆栈
   - 严重程度颜色标记

7. **日志 Tab**
   - 可滚动的日志列表
   - 时间、级别、服务、消息
   - 级别标签：error（红色）

8. **性能 Tab**
   - 两栏布局
   - 左：慢工具调用列表
   - 右：热文件访问排行

### 响应式设计
- 桌面端：2x2 图表网格
- 平板端：1x2 图表网格
- 移动端：单列堆叠

### 颜色方案
- 主色：#2563eb（蓝色）
- 成功：#16a34a（绿色）
- 警告：#f59e0b（黄色）
- 错误：#dc2626（红色）
- 背景：#0f0f1a（深色模式）
- 卡片：#1a1a2e（深色卡片）
- 文字：#e8eaed（主文字）
- 次要文字：#9aa0a6

### 字体系统
- 标题：24px/600
- 卡片标题：16px/600
- 数字：32px/700（KPI 卡片）
- 正文：14px/400
- 辅助文字：12px/400
- 等宽字体：'SF Mono', Monaco, Consolas（用于代码、时间戳）

### 间距系统
- 页面边距：24px
- 卡片间距：16px
- 元素间距：8px / 12px / 16px / 24px
- 圆角：8px（卡片）、6px（按钮）、4px（标签）
