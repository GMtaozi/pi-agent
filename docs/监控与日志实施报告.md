## 一、实现内容

### 1. Logging 包（packages/logging/）

**Logger 类**：
- 支持日志级别：debug、info、warn、error
- 结构化日志输出
- 上下文信息支持
- 错误堆栈记录

**MetricsCollector 类**：
- 指标记录与查询
- 平均值计算
- 自动清理旧指标

### 2. Server 集成

**新增日志**：
- 请求处理日志（sessionId、textLength）
- 错误日志（带堆栈）
- 性能指标（prompt.duration）

**代码示例**：
```typescript
const logger = new Logger({ service: 'server', level: 'info' });
const metrics = new MetricsCollector();

logger.info('Processing prompt', { sessionId: id, textLength: text.length });
const duration = Date.now() - startTime;
metrics.record('prompt.duration', duration, { sessionId: id });
logger.info('Prompt completed', { sessionId: id, responseLength: response.length, duration });
```

### 3. AgentEngine 集成

**新增日志**：
- 流式错误日志
- 调试信息

**代码示例**：
```typescript
this.logger.error('Stream error', { error: error instanceof Error ? error.message : String(error) }, error);
```

### 4. WorkspaceService 集成

**新增日志**：
- 文件读取日志（debug）
- 文件写入日志（info + size）
- 文件删除日志（info）

### 5. Tools 集成

**新增日志**：
- ReadFileTool：执行日志、成功/失败日志
- WriteFileTool：执行日志、成功/失败日志
- EditFileTool：执行日志、成功/失败日志
