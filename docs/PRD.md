## 1. 产品概述

### 1.1 一句话定义

> **Pi-Console：让每个人都能轻松搭建和管理 AI 智能体的平台。**

### 1.2 产品使命

让 AI 技术不再是大厂和程序员的专利。无论你是写文章、做客服、管店铺还是搞技术，都能通过 Pi-Console 快速拥有一个专属的 AI 智能体，帮你自动完成重复性工作。

### 1.3 产品价值

| 你是... | 你能做什么 |
|---------|-----------|
| 自媒体博主 | 用 AI 自动写文案、生成标题、回复评论 |
| 电商店主 | 搭建智能客服，24小时自动回复买家咨询 |
| 培训机构 | 制作 AI 助教，自动批改作业、回答学生问题 |
| 程序员 | 快速搭建 Agent 原型，调试复杂工作流 |
| 企业运营 | 构建自动化报告生成、数据分析流水线 |

### 1.4 产品特点

- **零门槛**：像搭积木一样简单，不需要写代码
- **可视化**：所有流程一目了然，所见即所得
- **开箱即用**：内置模板，5 分钟上线第一个智能体
- **按需扩展**：从简单对话到复杂工作流，随用随学

## 2. 目标用户

### 2.1 用户分层

#### 第一层：普通用户（60%）

| 属性 | 描述 |
|------|------|
| 人群 | 自媒体、店主、教师、学生、运营 |
| 技术能力 | 会用微信，不会写代码 |
| 需求 | 快速搭建一个能用的 AI 助手 |
| 使用方式 | 选择模板 → 填写内容 → 发布使用 |

**典型用户画像**：

> **小王，28岁，小红书博主**  
> 每天要写 5 篇笔记，还要回复粉丝评论。希望有个 AI 能帮她生成笔记草稿、自动回复常见问题。  
> 使用场景：选择"内容创作助手"模板 → 填入账号风格 → 生成笔记 → 发布

> **李老板，45岁，淘宝店主**  
> 店铺每天几百条咨询，客服成本高。想要一个能自动回答尺码、物流、退换货问题的 AI 客服。  
> 使用场景：上传商品信息 → 设置常见问题 → 接入店铺客服

#### 第二层：进阶用户（30%）

| 属性 | 描述 |
|------|------|
| 人群 | 产品经理、技术爱好者、中小企业技术负责人 |
| 技术能力 | 懂基础技术，能写简单脚本 |
| 需求 | 定制复杂工作流，集成多个系统 |
| 使用方式 | 拖拽编排工作流 → 配置节点 → 调试发布 |

**典型用户画像**：

> **张经理，32岁，SaaS 公司产品经理**  
> 需要为公司客户搭建一个能调用内部 API 的 AI 助手，能查数据、生成报告。  
> 使用场景：创建工作流 → 添加 HTTP 节点调用内部接口 → 添加 LLM 节点生成报告 → 发布

#### 第三层：专业用户（10%）

| 属性 | 描述 |
|------|------|
| 人群 | AI 工程师、架构师、技术团队负责人 |
| 技术能力 | 精通开发，需要深度定制 |
| 需求 | 构建生产级 Agent，需要完整可观测性 |
| 使用方式 | 使用 SDK/API → 深度定制 → 监控运维 |

### 2.2 用户核心痛点

| 痛点 | 描述 | 解决方案 |
|------|------|----------|
| 不会写代码 | 想用 AI 能力但不会编程 | 可视化拖拽，零代码搭建 |
| 调试困难 | AI 回复不符合预期，不知道怎么改 | 实时预览、变量检查、执行日志 |
| 成本失控 | 不知道 AI 调用了多少次，花了多少钱 | 实时成本统计、预算上限 |
| 知识不足 | AI 不了解我的业务知识 | 知识库上传，让 AI 学习你的资料 |
| 流程复杂 | 一个任务需要多步骤完成 | 工作流编排，自动化执行 |

## 3. 核心场景

### 场景一：智能客服

**用户**：电商店主、服务行业经营者

**需求**：7×24 小时自动回复客户咨询

**解决方案**：
1. 上传商品手册、常见问题文档到知识库
2. 选择"智能客服"模板
3. 配置 AI 人设（语气、风格、禁止回答的问题）
4. 接入微信/网站/APP

**效果**：
- 常见问题自动回答，准确率 > 90%
- 复杂问题转人工，附带对话记录
- 客服成本降低 70%

---

### 场景二：内容创作

**用户**：自媒体博主、内容运营

**需求**：批量生成高质量文案

**解决方案**：
1. 选择"内容创作助手"模板
2. 输入主题、目标受众、写作风格
3. 一键生成标题、正文、标签
4. 支持批量生成，一次 10 篇

**效果**：
- 单篇内容生成时间从 2 小时 → 2 分钟
- 支持小红书、公众号、抖音等多平台风格
- 自动优化 SEO 关键词

---

### 场景三：数据处理

**用户**：财务、运营、数据分析师

**需求**：定期生成数据报告

**解决方案**：
1. 连接数据源（数据库/Excel/API）
2. 设计数据处理流程
3. 设置定时执行（每天/每周）
4. 自动生成报告并发送到邮箱/企业微信

**效果**：
- 日报生成从 1 小时 → 自动完成
- 支持异常数据自动告警
- 报告格式统一，可直接汇报

---

### 场景四：教育辅导

**用户**：培训机构、教师、自学者

**需求**：个性化学习辅导

**解决方案**：
1. 上传教材、课件到知识库
2. 配置 AI 助教人设
3. 设置互动模式（讲解/测试/问答）
4. 学生通过对话学习

**效果**：
- 每个学生都有专属 AI 助教
- 自动批改作业，生成错题分析
- 教师工作量减少 50%

---

### 场景五：开发调试

**用户**：AI 工程师、程序员

**需求**：快速搭建和调试 Agent 原型

**解决方案**：
1. 可视化编排工作流
2. 实时调试，查看每个节点的输入输出
3. Token 消耗追踪
4. 一键导出代码

**效果**：
- 原型开发时间从 3 天 → 3 小时
- 调试过程透明可控
- 可直接导出为生产代码

| 术语 | 定义 |
|------|------|
| 智能体 | 一个配置好模型、参数、提示词的 AI 实体 |
| 工作流 | 由节点和连线组成的自动化流程 |
| 知识库 | 文档集合，供 AI 检索参考 |
| 工具 | AI 可以调用的外部功能 |
| Token | AI 计费的单位 |
| 提示词 | 给 AI 的指令 |
| 模型 | AI 的大脑，如 GPT-4、Claude |

### B. 常见问题

**Q：不会写代码能用吗？**
A：完全可以。选择模板，填写内容即可创建智能体。

**Q：支持哪些 AI 模型？**
A：支持 OpenAI（GPT-4/4o）、Anthropic（Claude）、国产模型（文心、通义等）、本地部署模型。

**Q：数据安全吗？**
A：所有数据加密存储，API Key 加密处理，支持私有部署。

**Q：如何接入微信？**
A：在发布设置中选择"微信接入"，按教程配置即可。

**Q：费用怎么计算？**
A：按实际使用的 Token 数量计费，不同模型价格不同，详见定价页面。
