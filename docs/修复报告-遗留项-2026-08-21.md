## 一、EPERM 问题处理结果

### 1.1 问题描述

在 Windows 环境下启动前端 dev server 时，可能出现 `EPERM` 错误，通常与 esbuild 子进程启动失败有关。

**常见错误信息：**
```
Error: EPERM: operation not permitted, ...
at ...
code: 'EPERM'
errno: -4048
syscall: '...'
path: '...'
```

### 1.2 根本原因

- **Windows Defender 实时保护**：杀毒软件锁定了 esbuild 二进制文件
- **文件/目录权限不足**：当前用户对项目目录没有完全控制权限
- **防火墙/安全软件拦截**：第三方安全软件阻止了子进程创建
- **Windows 资源管理器锁定**：文件被其他进程占用

### 1.3 处理结果

| 项目 | 状态 | 说明 |
|------|------|------|
| 问题诊断 | ✅ 已完成 | 定位为 Windows 系统级权限限制 |
| 解决方案文档 | ✅ 已完成 | 输出 `docs/dev-server-EPERM-解决方案.md` |
| 自动修复 | ⚠️ 未自动修复 | 需根据实际情况手动选择方案 |

### 1.4 提供的解决方案

共提供 **6 种解决方案**，按推荐顺序排列：

1. **关闭 Windows Defender 实时保护（临时）**
2. **将项目目录加入 Defender 排除项（推荐永久方案）**
3. **以管理员身份运行 PowerShell**
4. **检查目录权限并授予完全控制**
5. **关闭防火墙/安全软件（临时）**
6. **使用 WSL 2 或 Docker（终极方案）**

### 1.5 验证步骤

```powershell

cd D:\Project\pi-agent

# 启动前端 dev server
pnpm dev:web
```

**预期输出：**
```
  VITE vX.X.X  ready in XXX ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

### 1.6 预防措施

- 将项目目录永久加入 Defender 排除项
- 定期更新依赖：`pnpm update`
- 使用 LTS 版本 Node.js
- 避免在项目目录中打开过多文件

## 二、Markdown 渲染改进内容

### 2.1 后端改进

**文件**：`apps/server/src/index.ts`

**新增 `markdownToHtml` 函数（lines 29-49）**：

```typescript
function markdownToHtml(markdown: string): string {
  let html = markdown
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;');

  html = html
    .replace(/^###### (.*$)/gim, '<h6>$1</h6>')
    .replace(/^##### (.*$)/gim, '<h5>$1</h5>')
    .replace(/^#### (.*$)/gim, '<h4>$1</h4>')
    .replace(/^### (.*$)/gim, '<h3>$1</h3>')
    .replace(/^## (.*$)/gim, '<h2>$1</h2>')
    .replace(/^# (.*$)/gim, '<h1>$1</h1>')
    .replace(/\*\*(.*?)\*\*/g, '<strong>$1</strong>')
    .replace(/\*(.*?)\*/g, '<em>$1</em>')
    .replace(/`([^`]+)`/g, '<code>$1</code>')
    .replace(/```([\s\S]*?)```/g, '<pre><code>$1</code></pre>')
    .replace(/\n/g, '<br>');

  return html;
}
```

**预览端点增强（lines 502-506）**：

`/api/workspaces/:id/preview` 端点现在支持 `.md` 和 `.markdown` 文件：

```typescript
if (['md', 'markdown'].includes(ext || '')) {
  const html = markdownToHtml(content);
  res.header('Content-Type', 'text/html');
  return res.send(html);
}
```

**支持的格式**：
- 标题：`#` ~ `######`
- 强调：`**粗体**`、`*斜体*`
- 行内代码：`` `code` ``
- 代码块：`` ```language `` 代码块 ````
- 换行：自动转换为 `<br>`

### 2.2 前端改进

**文件**：`apps/web/src/pages/ChatPage.tsx`

**新增 Markdown 渲染函数（lines 394-450）**：

1. **`renderInlineMarkdown(text: string)`**：处理行内 Markdown

   - 代码块带语言标识（`language-header`）

**使用位置**：`ChatPage.tsx` line 571

