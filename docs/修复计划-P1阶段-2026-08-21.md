### P1-3：产物预览 T3.2

**状态**：部分实现，待完善

**文件**：`apps/server/src/index.ts`

**当前实现**：
```ts
// /api/workspaces/:id/preview
server.get('/api/workspaces/:id/preview', async (req, res) => {
  const { id } = req.params;
  const path = req.query.path;
  const content = await workspaceService.readFile(id, path);
  const ext = path.split('.').pop()?.toLowerCase();
  
  // HTML: 直接返回
  if (['html', 'htm'].includes(ext)) {
    res.header('Content-Type', 'text/html');
    return res.send(content);
  }
  
  // 图片: redirect 到 files/content
  if (['png', 'jpg', 'jpeg', 'webp', 'gif', 'bmp', 'svg'].includes(ext)) {
    return res.redirect('/api/workspaces/' + id + '/files/content?path=' + encodeURIComponent(path));
  }
  
  // 其他: 返回 JSON
  return { type: ext, content, size: content.length };
});
```

**前端实现**（`WorkspacePage.tsx`）：
- HTML 文件：使用 iframe + `srcDoc` 预览，设置 `sandbox="allow-scripts allow-same-origin"`
- 图片：通过 `files/content` 接口获取并展示

**待完善功能**：

### P1-8：WebSocket 前端消费端完善

**状态**：进行中（t8，frontend-fixer）

**文件**：`apps/web/src/hooks/useWorkspaceRefresh.ts`

**当前实现**：
```ts
export function useWorkspaceRefresh(onFileChange: (path: string) => void) {
  const connect = useCallback(() => {
    const ws = new WebSocket(protocol + '//' + window.location.host + '/ws');
    
    ws.onopen = () => console.log('WebSocket connected');
    ws.onmessage = (event) => {
      const data: FileChangeMessage = JSON.parse(event.data);
      if (data.type === 'file-changed') {
        onFileChangeRef.current(data.path);
      }
    };
    ws.onclose = () => {
      console.log('WebSocket disconnected, reconnecting in 3s...');
      reconnectTimerRef.current = window.setTimeout(() => connect(), 3000);
    };
    ws.onerror = (err) => console.error('WebSocket error:', err);
  }, []);
}
```

**已实现功能**：
- 自动连接 `/ws` 端点
- 解析 `file-changed` 消息并回调
- 断开后 3 秒自动重连
- 清理副作用（关闭连接、清除定时器）

**待完善功能**：
1. **消息类型扩展**
   - 当前只处理 `file-changed`，建议增加 `file-created`、`file-deleted`、`file-renamed`
   - 前端根据消息类型执行不同操作（新增/删除/重命名文件）

2. **连接状态暴露**
   - 增加 `connectionState`：`connecting` / `open` / `closing` / `closed`
   - 前端 UI 显示 WebSocket 连接状态（如绿色圆点表示已连接）

3. **错误处理增强**
   - `onerror` 时设置连接状态为 `error`
   - 增加 `onFileChangeError` 回调，通知上层文件刷新失败

4. **心跳机制**
   - 增加 `ping/pong` 心跳，检测连接是否真正存活
   - 超过 2 次 `ping` 无响应则强制重连

5. **多 workspace 支持**
   - 当前 `/ws` 是全局连接，建议增加 `workspaceId` 过滤
   - 服务端只推送当前 workspace 的文件变更

**验证策略**：
- 单元测试：模拟 WebSocket 消息，验证 `onFileChange` 回调
- 集成测试：修改文件，验证前端自动刷新
- 手动测试：断开网络，验证 3 秒后自动重连
