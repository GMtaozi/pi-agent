## 一、实现内容

### 1. Monitoring 包（packages/monitoring/）

**MetricsDashboard 类**：
- 记录请求总数、成功数、失败数
- 记录工具调用次数和耗时
- 记录最近错误
- 计算平均耗时

**MonitoringService 类**：
- 封装 MetricsDashboard
- 提供日志集成
- 提供 API 数据接口

### 2. Server 监控端点

**新增 API**：
- `GET /api/monitoring/dashboard` - 获取仪表盘数据
- `GET /api/monitoring/metrics` - 获取指标摘要
- `POST /api/monitoring/reset` - 重置指标

### 3. 集成点

**Prompt 端点**：
- 记录请求成功/失败
- 记录请求耗时
- 失败时自动标记

**工具调用**：
- 记录工具名称
- 记录工具耗时

### 4. 前端仪表盘

**页面**：MonitoringPage

**功能**：
- 自动刷新（5 秒）
- 显示关键指标卡片
- 工具使用统计
- 最近错误列表

**指标卡片**：
- 运行时间（Uptime）
- 总请求数
- 成功率
- 平均耗时
- 内存使用
