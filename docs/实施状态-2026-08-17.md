## 当前阻塞

即使退出火绒，dev server 仍无法启动，错误为：

```
Error: spawn EPERM
    at ChildProcess.spawn
    at ensureServiceIsRunning (...esbuild...)
```

这是 **esbuild 二进制/服务进程启动被系统策略阻止**，不是代码错误。

## 可能原因

1. Windows Defender 实时保护/隔离
2. SmartScreen 或应用和浏览器控制
3. 企业/组策略限制子进程创建
4. Node.js 目录权限不足
5. 防病毒仍残留钩子（非火绒）

## 建议排查步骤

1. 检查 `D:\Project\pi-agent\node_modules\.pnpm\esbuild@*` 下的二进制是否存在
2. 临时关闭 Windows Defender 实时保护后重试
3. 将项目目录加入 Defender 排除项
4. 检查 `D:\nodejs\node.exe` 是否可被当前用户执行
5. 在普通 PowerShell（非管理员）与管理员 PowerShell 下分别试 `pnpm run dev`
