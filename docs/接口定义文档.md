## 1. 认证接口

### 1.1 用户注册

```
POST /api/v1/auth/register
Content-Type: application/json

Request:
{
  "email": "user@example.com",
  "password": "securePassword123",
  "name": "张三"
}

Response (201):
{
  "success": true,
  "data": {
    "userId": "usr_abc123",
    "email": "user@example.com",
    "name": "张三",
    "createdAt": "2026-09-02T14:30:00Z"
  }
}

Error (400):
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "邮箱格式不正确"
  }
}

Error (409):
{
  "success": false,
  "error": {
    "code": "USER_EXISTS",
    "message": "该邮箱已被注册"
  }
}
```

### 1.2 用户登录

```
POST /api/v1/auth/login
Content-Type: application/json

Request:
{
  "email": "user@example.com",
  "password": "securePassword123"
}

Response (200):
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIs...",
    "expiresIn": 604800,
    "user": {
      "userId": "usr_abc123",
      "email": "user@example.com",
      "name": "张三"
    }
  }
}

Error (401):
{
  "success": false,
  "error": {
    "code": "INVALID_CREDENTIALS",
    "message": "邮箱或密码错误"
  }
}
```

### 1.3 刷新 Token

```
POST /api/v1/auth/refresh
Content-Type: application/json

Request:
{
  "refreshToken": "eyJhbGciOiJIUzI1NiIs..."
}

Response (200):
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "expiresIn": 604800
  }
}
```

### 1.4 获取当前用户

```
GET /api/v1/auth/me
Authorization: Bearer <token>

Response (200):
{
  "success": true,
  "data": {
    "userId": "usr_abc123",
    "email": "user@example.com",
    "name": "张三",
    "avatar": "https://...",
    "plan": "professional",
    "createdAt": "2026-09-01T10:00:00Z"
  }
}
```

## 3. 会话接口

### 3.1 创建会话

```
POST /api/v1/sessions
Authorization: Bearer <token>
Content-Type: application/json

Request:
{
  "agentId": "agt_abc123",
  "title": "新对话"
}

Response (201):
{
  "success": true,
  "data": {
    "sessionId": "ses_abc123",
    "agentId": "agt_abc123",
    "title": "新对话",
    "status": "active",
    "createdAt": "2026-09-02T14:30:00Z"
  }
}
```

### 3.2 发送消息（流式）

```
POST /api/v1/sessions/:sessionId/messages
Authorization: Bearer <token>
Content-Type: application/json
Accept: text/event-stream

Request:
{
  "content": "你好，我想查询订单状态",
  "stream": true
}

Response (SSE):
event: message_start
data: {"messageId": "msg_001"}

event: content_chunk
data: {"delta": "您好！"}

event: content_chunk
data: {"delta": "请提供您的订单号"}

event: message_complete
data: {
  "messageId": "msg_001",
  "content": "您好！请提供您的订单号",
  "tokens": 50,
  "cost": 0.001,
  "duration": 800
}

event: error
data: {"code": "MODEL_ERROR", "message": "模型调用失败"}
```

### 3.3 停止生成

```
POST /api/v1/sessions/:sessionId/stop
Authorization: Bearer <token>

Response (200):
{
  "success": true,
  "data": {
    "message": "已停止生成"
  }
}
```

### 3.4 获取会话历史

```
GET /api/v1/sessions/:sessionId/messages?page=1&limit=50
Authorization: Bearer <token>

Response (200):
{
  "success": true,
  "data": {
    "items": [
      {
        "messageId": "msg_001",
        "role": "user",
        "content": "你好，我想查询订单状态",

      },
      {
        "messageId": "msg_002",
        "role": "assistant",
        "content": "您好！请提供您的订单号",
        "tokens": 50,
        "cost": 0.001,
        "createdAt": "2026-09-02T14:30:05Z"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 50,
      "total": 10,
      "totalPages": 1
    }
  }
}
```

## 9. WebSocket 接口

### 9.1 连接

```
WS /ws?token=<jwt_token>
```

### 9.2 消息类型

#### 客户端 → 服务器

```typescript
// 订阅执行状态
{
  "type": "subscribe_execution",
  "executionId": "exec_001"
}

// 取消订阅
{
  "type": "unsubscribe_execution",
  "executionId": "exec_001"
}

// 调试操作
{
  "type": "debug_action",
  "debugSessionId": "dbg_001",
  "action": "step" | "continue" | "abort"
}
```

#### 服务器 → 客户端

```typescript
// 执行开始
{
  "type": "execution_started",
  "executionId": "exec_001",
  "timestamp": "2026-09-02T14:30:00Z"
}

// 节点开始
{
  "type": "node_started",
  "executionId": "exec_001",
  "nodeId": "node_001",
  "nodeType": "llm",
  "timestamp": "2026-09-02T14:30:00Z"

// 节点完成

  "type": "node_completed",
```

## 10. 错误码定义

| 错误码 | HTTP 状态码 | 说明 |
|--------|-------------|------|
| `VALIDATION_ERROR` | 400 | 请求参数验证失败 |
| `UNAUTHORIZED` | 401 | 未认证或 Token 无效 |
| `FORBIDDEN` | 403 | 无权限访问 |
| `NOT_FOUND` | 404 | 资源不存在 |
| `USER_EXISTS` | 409 | 用户已存在 |
| `AGENT_NOT_FOUND` | 404 | 智能体不存在 |
| `KNOWLEDGE_BASE_NOT_FOUND` | 404 | 知识库不存在 |
| `TOOL_NOT_FOUND` | 404 | 工具不存在 |
| `ARTIFACT_NOT_FOUND` | 404 | 产物不存在 |
| `EXECUTION_NOT_FOUND` | 404 | 执行记录不存在 |
| `MODEL_ERROR` | 502 | 模型调用失败 |
| `TOOL_ERROR` | 502 | 工具调用失败 |
| `RATE_LIMIT_EXCEEDED` | 429 | 请求频率超限 |
| `INTERNAL_ERROR` | 500 | 服务器内部错误 |
