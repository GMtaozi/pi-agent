## 一、安全（已修复 🔒）

### 🔴 S1. 硬编码密钥回退 → 已修复
**文件**：`packages/auth/src/index.ts:31-33`
**修复**：`JWT_SECRET`/`REFRESH_SECRET`/`API_KEY_ENCRYPTION_KEY` 缺失时 `throw Error` 拒绝启动，不再使用明文默认值。

### 🔴 S2. `.env.example` 不完整 → 已修复
**文件**：`.env.example`
**修复**：补全所有密钥项并标注必填，移除 `change-me` 占位值。

### 🔴 S3. 遗留登录接受客户端 `tenantId` → 已修复
**文件**：`apps/server/src/index.ts:529-538`
**修复**：`tenantId` 由服务端硬编码为 `'default'`，不再从请求体取值。

### 🔴 S4. 开发默认开放登录 → 已修复
**文件**：`apps/server/src/index.ts:528-540`
**修复**：未设 `ADMIN_PASSWORD` 且未显式 `ALLOW_OPEN_LOGIN=true` 时，登录返回 403。

### 🟠 S5. 弱密钥派生（零填充）→ 已修复
**文件**：`packages/auth/src/index.ts:97-117`、`apps/server/src/encryption.ts:8-16`
**修复**：使用 `scryptSync` 派生 32 字节密钥，API Key 加密增加随机 salt。

### 🟠 S6. 认证路由前缀不匹配 → 已修复
**文件**：`apps/server/src/index.ts:243`
**修复**：白名单增加 `/api/v1/auth/` 前缀，v1 认证端点不再死代码。

### 🟠 S7. 日志泄露令牌 → 已修复
**文件**：`apps/server/src/index.ts:241`
**修复**：记录 URL 前剥离 `?token=...` 参数。
