## 一、实现内容

### 1. 新建 Tools 包（packages/tools/）

**包名**：`@workforge/tools`

**核心类**：
- `BaseTool`：抽象基类，实现 `AgentTool` 接口
- `ReadFileTool`：读取文件
- `WriteFileTool`：写入文件
- `EditFileTool`：编辑文件（替换文本）

### 2. BaseTool 抽象类

**接口实现**：

```typescript
export abstract class BaseTool implements AgentTool {
  abstract name: string;
  abstract description: string;
  abstract parameters: any;
  abstract label: string;
  
  constructor(protected options: BaseToolOptions) {}
  
  abstract execute(
    toolCallId: string,
    params: any,
    signal?: AbortSignal,
    onUpdate?: (partial: any) => void
  ): Promise<AgentToolResult<any>>;
}
```

**属性**：
- `options.workspaceService`：工作台服务
- `options.workspaceId`：当前工作台 ID

### 3. ReadFileTool

**功能**：读取工作台中的文件

**参数**：
```json
{
  "path": "string" // 文件路径
}
```

**执行流程**：
1. 调用 `workspaceService.readFile(workspaceId, path)`
2. 返回文件内容
3. 错误时返回错误信息

### 4. WriteFileTool

**功能**：写入文件到工作台

**参数**：
```json
{
  "path": "string",   // 文件路径
  "content": "string" // 文件内容
}
```

**执行流程**：
1. 调用 `workspaceService.writeFile(workspaceId, path, content)`
2. 返回成功消息
3. 错误时返回错误信息

### 5. EditFileTool

**功能**：编辑文件（精确替换）

**参数**：
```json
{
  "path": "string",   // 文件路径
  "oldText": "string", // 要替换的文本
  "newText": "string"  // 新文本
}
```

**执行流程**：
1. 读取当前文件内容
2. 检查 `oldText` 是否存在
3. 执行替换
4. 写回文件
5. 返回成功消息

### 6. createWorkspaceTools 工厂函数

```typescript
export function createWorkspaceTools(
  workspaceService: WorkspaceService,
  workspaceId: string
): AgentTool[] {
  return [
    new ReadFileTool({ workspaceService, workspaceId }),
    new WriteFileTool({ workspaceService, workspaceId }),
    new EditFileTool({ workspaceService, workspaceId }),
  ];
}
```

### 7. Server 集成

**POST /api/sessions 端点**：

```typescript
server.post('/api/sessions', async (req, res) => {
  const { model, workspaceId } = req.body || {};
  
  // 为 session 创建工具
  const tools = createWorkspaceTools(workspaceService, workspaceId || 'default');
  
  // 创建带工具的 session
  const session = await agentEngine.createSession(model || 'default', tools);
  
  // 映射 session 到 workspace
  sessionWorkspaces.set(session.id, workspaceId || 'default');
  
  return { session: { id: session.id, model: session.model } };
});
```

### 8. AgentEngine 集成

**createSession 方法增强**：

```typescript
async createSession(
  model: string,
  tools?: AgentTool<any>[]
): Promise<SessionInfo> {
  const agent = new Agent({
    sessionId: id,
    initialState: {
      systemPrompt: this.defaultSystemPrompt,
      tools: tools || this.defaultTools, // 使用传入的工具
    },
    streamFn: this.createStreamFn(),
    getApiKey: (provider: string) => this.settingsService.getApiKey(provider),
  });
  
  this.sessions.set(id, agent);
  return { id, model };
}
```

## 二、工具调用数据流

```
用户输入: "把 index.html 的标题改大"
  -> Agent 解析为工具调用
    -> tool_call: {
         name: "read_file",
         arguments: { path: "index.html" }
       }
  -> Pi SDK Agent 循环执行工具
    -> ReadFileTool.execute(toolCallId, { path: "index.html" })
      -> workspaceService.readFile("default", "index.html")
      <- 返回文件内容
    -> Agent 收到工具结果，生成新的 assistant 消息
      -> tool_call: {
           name: "edit_file",
           arguments: {
             path: "index.html",
             oldText: "<title>旧标题</title>",
             newText: "<title style="font-size: 24px;">新标题</title>"
           }
         }
    -> EditFileTool.execute(toolCallId, args)
      -> workspaceService.readFile("default", "index.html")
      -> workspaceService.writeFile("default", "index.html", newContent)
      <- 返回成功消息
  -> Agent 生成最终回复
  -> 通过 SSE 流式发送到前端
```
