## 二、Phase 0 详细任务拆解（2-4 周）

### 第 1 周：项目初始化与基础设施

#### T1.1 初始化 monorepo 结构
- 创建根目录结构：apps/、packages/、skills/、docs/
- 初始化根 package.json、pnpm-workspace.yaml
- 配置 tsconfig.base.json、biome.json、.gitignore
- 配置基础脚本：build、check、test

**交付物**：
- 根目录配置文件
- workspace 配置
- CI 基础流水线

**验收标准**：
- pnpm install 成功
- pnpm build 成功
- pnpm check 无错误

#### T1.2 接入 Pi SDK 作为本地依赖
- 将 D:\GitHub\pi 作为本地 workspace 依赖或 file 依赖接入
- 配置 packages/agent-engine 作为适配层
- 验证 Pi SDK 可被正确引用和构建

**交付物**：
- packages/agent-engine 基础封装
- 依赖配置

**验收标准**：
- 可在代码中 import Pi SDK 模块
- 基础类型编译通过

#### T1.3 初始化后端服务骨架
- 创建 apps/server 目录
- 配置 Fastify
- 配置 SSE 和 WebSocket 服务
- 配置 SQLite 初始化
- 配置日志与错误处理中间件

**交付物**：
- apps/server 基础 HTTP 服务
- 健康检查接口

**验收标准**：
- node dist/server.js 启动成功
- GET /health 返回 200

#### T1.4 初始化前端骨架
- 创建 apps/web React + Vite 项目
- 配置基础布局：侧边栏 + 主区域 + 右侧面板
- 配置 HTTP/WebSocket 客户端

**交付物**：
- apps/web 基础页面
- 布局组件

**验收标准**：
- pnpm dev:web 启动成功
- 浏览器可访问本地页面


---

### 第 2 周：Agent 引擎与会话服务

#### T2.1 封装 AgentSession 适配层
- 在 packages/agent-engine 中封装 Pi SDK 的 AgentSession
- 实现模型切换接口
- 实现会话生命周期管理

**交付物**：
- AgentEngine 类
- 会话工厂方法

**验收标准**：
- 可创建 AgentSession
- 可切换模型
- 可发送 prompt 并收到流式响应

#### T2.2 实现会话服务 API
- POST /api/sessions：创建会话
- GET /api/sessions：列出会话
- GET /api/sessions/:id：会话详情
- DELETE /api/sessions/:id：删除会话
- SSE 端点：/api/sessions/:id/stream

**交付物**：
- 会话 REST API
- SSE 流式端点

**验收标准**：
- Postman/curl 可创建会话
- SSE 可接收流式消息

#### T2.3 实现基础工具注册
- 注册 read、write、edit 工具
- 工具执行权限默认策略：工作台内 Do，工作台外 Review
- 工具执行结果回调

**交付物**：
- 工具注册表
- 权限拦截器

**验收标准**：
- Agent 可调用 read/write/edit
- 工作台外写操作被拦截并记录

---

### 第 3 周：工作台服务与前端对话

#### T3.1 工作台目录服务
- 实现工作台目录扫描
- 文件树 API（忽略 .git/node_modules 等）
- 文件 CRUD API

**交付物**：
- GET /api/workspaces/:id/files：文件树
- POST /api/workspaces/:id/files：新建文件
- DELETE /api/workspaces/:id/files/:path：删除文件

**验收标准**：
- 前端可看到工作台文件树
- 可新建/删除文件

#### T3.2 产物预览代理
- HTML 预览：沙箱 iframe + CSP
- 图片/视频/音频：静态文件服务 + 正确 Content-Type
- Markdown：前端渲染（可选后端预渲染）

**交付物**：
- GET /api/workspaces/:id/preview/:path：预览代理
- 静态资源服务

**验收标准**：
- HTML 可在沙箱 iframe 中预览
- 图片/视频可正常播放

#### T3.3 前端对话面板
- 对话流组件：消息列表、Markdown 渲染、代码高亮
- 输入框：模型选择、图片粘贴、Enter 发送
- 流式更新：SSE 客户端集成
- 中止按钮

**交付物**：
- 对话 UI 组件
- SSE 客户端 hook

**验收标准**：
- 用户可发送消息
- Agent 回复流式渲染
- 可切换模型

#### T3.4 前端工作台面板
- 文件树组件
- 预览器组件
- 右键菜单：重命名/删除/下载/让 Agent 改

**交付物**：
- 文件树 UI
- 预览器 UI

**验收标准**：
- 文件树实时刷新
- 点击文件可预览

---

### 第 4 周：修订闭环与 Phase 0 验收

#### T4.1 产物引用解析
- 对话上下文注入文件树 + 文件内容摘要
- Agent 提示词模板支持引用文件（如“把 5.html 标题改大”）

**交付物**：
- 上下文构建器
- 提示词模板

**验收标准**：
- Agent 能理解“5.html”指代工作台中的文件

#### T4.2 原地修改与工作台刷新
- Agent 调用 edit 工具修改文件
- 文件监听（chokidar）触发 WebSocket 推送
- 前端自动刷新文件树和预览

**交付物**：
- 文件监听服务
- WebSocket 推送逻辑
- 前端自动刷新

**验收标准**：
- Agent 修改文件后，前端自动更新
- 无需手动刷新页面

#### T4.3 设置与密钥管理
- 设置页面：模型供应商 API Key 配置
- 密钥加密存储（AES-256-GCM）
- 前端永不见明文 Key

**交付物**：
- 设置页面 UI
- 密钥存储服务

**验收标准**：
- 用户可录入 API Key
- Key 加密存储在本地
- 后端可使用 Key 调用模型

#### T4.4 Phase 0 Go/No-Go 验收
- 完整主链路测试：对话生成 HTML → 工作台预览 → 修订闭环
- 切换模型测试
- API Key 配置测试
- 性能压测：首屏 < 2s，预览 < 1s

**交付物**：
- 验收测试报告
- 已知问题列表

**验收标准**：
- 全部 4 项 Go/No-Go 标准达成

## 五、风险登记册

| 风险 | 等级 | 影响 | 缓解措施 | 回退方案 |
|---|---|---|---|---|
| Pi SDK 版本不兼容 | 中 | 引擎接入延期 | 锁定 Pi 版本，fork 并打 patch | 回退到直接调用 OpenAI API |
| SSE/WebSocket 浏览器兼容 | 低 | 部分用户无法使用 | 提供轮询降级 | 纯轮询模式 |
| HTML 沙箱策略过于严格 | 中 | 产物预览受限 | 提供“允许脚本”选项 + 用户确认 | 降级为代码展示而非运行 |
| 文件监听性能问题 | 低 | 大工作台刷新延迟 | 目录忽略 + 增量扫描 | 手动刷新按钮兜底 |
| 模型 API 限流/成本 | 中 | 体验不稳定 | 多模型 fallback + 预算提醒 | 降低并发 + 提示用户 |
