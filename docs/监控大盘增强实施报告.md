## 一、增强内容

### 1. 时序数据（Time Series）

**MetricsDashboard 新增**：
- `requestTimeSeries`：请求数时序
- `durationTimeSeries`：耗时时序
- `errorTimeSeries`：错误数时序
- 最大 100 个数据点限制

### 2. 告警系统（Alerts）

**内置告警规则**：
| 规则 | 触发条件 | 严重程度 |
|------|----------|----------|
| high-error-rate | 错误率 > 20% | critical |
| slow-response | 平均耗时 > 5000ms | warning |
| high-memory | 内存使用 > 500MB | warning |

**功能**：
- 自动检测并触发告警
- 告警确认机制
- 最近 50 条告警记录

### 3. Server 新增端点

| 端点 | 方法 | 说明 |
|------|------|------|
| /api/monitoring/dashboard | GET | 仪表盘数据（含时序） |
| /api/monitoring/metrics | GET | 指标摘要 |
| /api/monitoring/alerts | GET | 告警列表 |
| /api/monitoring/alerts/:id/acknowledge | POST | 确认告警 |
| /api/monitoring/reset | POST | 重置指标 |

### 4. 前端增强

**MonitoringPage 新增**：
- **时序图表**：请求趋势、响应耗时、错误趋势
- **告警标签页**：显示未确认告警，支持确认操作
- **自动刷新**：每 5 秒更新

### 5. 工具监控集成

**改动**：
- `BaseToolOptions` 新增 `onToolCall` 回调
- 所有工具（ReadFileTool、WriteFileTool、EditFileTool）记录：
  - 工具名称
  - 执行耗时
  - 成功/失败状态

### 6. 监控链路

```
Server → MonitoringService
  ├── recordRequest(success, duration)
  ├── recordToolCall(toolName, duration, success)
  └── recordError(message, service)

Tools → onToolCall callback
  └── monitoring.recordToolCall(toolName, duration, success)
```
