# WorkForge 代码修复报告

> 日期：2026-08-17
> 状态：P0/P1 问题已修复，类型检查通过（vendor pi 上游错误除外）

---

## 一、修复的问题

### 1. Workspace 路径穿越漏洞（P0）
**文件**：packages/workspace/src/workspace.ts

**修复前**：
- readFile/writeFile/deleteFile 直接使用用户传入路径
- 没有校验是否在 workspace 根目录内
- 恶意输入 `../../../etc/passwd` 可访问工作区外文件

**修复后**：
- 新增 `validatePath()` 方法
- 使用 `normalize()` 规范化路径
- 校验 `normalizedPath.startsWith(normalizedBase + '/')`
- 路径穿越时抛出明确错误

### 2. Workspace 未注册导致文件 API 不可用（P0）
**文件**：apps/server/src/index.ts

**修复前**：
- 实例化了 `workspaceService`
- 但从未调用 `workspaceService.register('default', path)`
- 所有文件 API 调用都会抛 `Workspace not found`

**修复后**：
- 添加 `DEFAULT_WORKSPACE_PATH`
- 启动时注册：`workspaceService.register('default', DEFAULT_WORKSPACE_PATH)`

### 3. 类型安全薄弱（P1）
**文件**：apps/server/src/index.ts

**修复前**：
- 大量使用 `(req.body as any)`
- `(req.params as any)`
- `(req.query as any)`

**修复后**：
- 定义 proper TypeScript interfaces：
  - `CreateSessionBody`
  - `PromptBody`
  - `WriteFileBody`
  - `DeleteFileBody`
  - `ApiKeyBody`
  - `MemoryBody`
- 使用 Fastify 泛型参数：
  - `server.get<{ Params: { id: string }; Reply: ... }>`
- 移除所有 `as any` 强制转换

### 4. 错误处理不完整（P1）
**文件**：apps/server/src/index.ts

**修复前**：
- catch 块只返回 `500` + 泛化消息
- 没有记录实际错误
- 前端拿不到有用信息

**修复后**：
- 每个 catch 块都添加 `server.log.error(err)`
- 保留错误日志用于调试
- 返回给前端统一的错误格式

### 5. Governance 上下文缺失（P1）
**文件**：apps/server/src/index.ts

**修复前**：
```typescript
const decision = governanceService.evaluate('delete');
```

**修复后**：
```typescript
const decision = governanceService.evaluate('delete', { workspaceId: id, filePath });
```

### 6. AgentEngine 仍未接入 Pi SDK（P1）
**文件**：packages/agent-engine/src/engine.ts

**修复前**：
- `createSession` / `prompt` 都是 stub 实现
- 没有 import `Agent`
- TODO 注释还在

**修复后**：
- 实际 import `Agent` 和 `AgentMessage` 等类型
- `createSession` 实例化真正的 `Agent` 对象
- 配置 `streamFn`、`getApiKey`、`systemPrompt`、`tools`
- `prompt` 调用 `agent.prompt(text)` 并提取响应
- 新增 `abort()`、`deleteSession()` 方法
- 添加 `SettingsService` 集成以获取 API Key
